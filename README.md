# wasen-home-page
Wasen Homepage 

Das ist eine einfache homepage on git hub. Die Seite soll ein modernes Erscheinungsbild haben besteht aus fünf Seiten. Einer "Startseite", "Kartenreservierung", "Bildergalerie", "Speisen und Getränke", "Über uns" und dem "Impressum". Die Seite wird vor allem von mobilen Endgeräten angesteuert werden. Des werden Bilder 

## Startseite 

Diese Indexseite enthät Ankündigungen und Infromationen zum Oedheimer Wasen. Einen Sponsorenteil; hier werden Sponsorenlogos gezeigt.

## Kartenreservierung
Auf dieser Seite wird beschrieben wie der Kartenreservierungsprozess abläuft. Die Seite verwaltet die Reservierung jedoch nicht.

## Speisen und Getränke
Hier werden Speisen und Getränke sowie die Preise während des Oedheimer Wasens gezeigt.

## Bildergalerie
Hier werden keine Bilder gezeigt. Die Seite dient zur Weiterleitung zu einer externen Bildergalerie bzw. Sozialen Medien.

## Über uns

Stellt den Förderverein der hinter dem Oedheimer Wasen steht vor.

## Impressum

Pflichtteil - typisches Impressum einer Webseite.
