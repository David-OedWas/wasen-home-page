## Kartenreservierung
Auf dieser Seite wird beschrieben wie der Kartenreservierungsprozess abläuft. Die Seite verwaltet die Reservierung jedoch nicht. der Reservierungsprozess sieht wie folgt aus: 

Für eine Online Tischreservierung senden Sie bitte die gewünschte Tischnummer und Ihren Namen an folgende E-Mail Adresse: reservierung@oedheimer-wasen.de . Bitte beachten Sie, dass eine Tischreservierung nur bei einer Abnahme von 10 Karten möglich ist. ​Einzelkarten können ebenfalls online erworben werden. Der Kartenpreis beträgt 28,00 € und beinhaltet neben dem Eintritt ein Getränk (Maß Bier ausgenommen) und ein halbes Hähnchen mit Brötchen, oder das vegetarische Gericht. Die Tischnummer und die Platzierung des Tisches im Zelt können Sie dem Zeltplan entnehmen. Den Plan können Sie unten im Button "Tischplan"einsehen.  Sie erhalten innerhalb von 24 Stunden eine Reservierungsbestätigung. Sollte der gewünschte Tisch für eine Vorverkaufsstelle reserviert sein, so bitten wir Sie die Karten dort zu erwerben und die Reservierung vor Ort zu tätigen (ab Sofort Verfügbar). Vorverkaufsstelle ist: Schreibwaren am Marktplatz in Oedheim. Vielen Dank Ihr Oedheimer Wasen Team

Link zum Tischplan Excel: https://docs.google.com/spreadsheets/d/13JUfNZdOf2O-yArDOvIWReevsp4BzR4_/edit?gid=1148013951#gid=1148013951
